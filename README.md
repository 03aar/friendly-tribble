# Engage - Intelligent Work Companion

> *The intelligent workplace companion that helps you succeed at your job, get recognized for your work, and stay fulfilled — without burning out.*

## 🎯 Overview

Engage is a comprehensive product designed to combine **performance management**, **emotional wellbeing**, and **career growth** into one seamless experience. This repository contains complete product documentation and a fully functional interactive prototype.

## 🚀 Quick Start

### View the Interactive Prototype

1. **Start a local server:**
   ```bash
   cd public
   python3 -m http.server 8000
   ```

2. **Open in your browser:**
   ```
   http://localhost:8000/index.html
   ```

3. **Experience the product:**
   - Splash screen animation
   - Sign up / Sign in flows
   - 7-step onboarding process
   - Main application with 4 core sections:
     - Goals (FlowBoard)
     - Team (KudosStream)
     - Grow (Learning paths)
     - You (Profile & progress)

## 🎨 Key Features in the Prototype

### 1. Authentication & Onboarding
- Welcome screen with branding
- Sign up / Sign in forms
- 7-step personalized onboarding:
  1. Welcome message
  2. Role definition
  3. Team selection
  4. Goal setting
  5. Mood tracking
  6. Work style preferences
  7. Completion with celebration

### 2. Main Application
- **FlowBoard**: Daily command center with prioritized tasks
- **GoalHub**: Track active goals with progress visualization
- **KudosStream**: Team recognition and appreciation
- **Profile**: Personal metrics and achievements

### 3. Interactive Elements
- Task completion with confetti animations
- Tab-based navigation
- Mood selection with emoji picker
- Progress tracking with visual indicators
- Smooth transitions and animations

## 🛠 Technical Details

### Technology Stack (Prototype)
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS variables
- **Vanilla JavaScript** - No dependencies
- **Responsive Design** - Mobile-first approach

### Design System
- Color palette with primary (#4A90E2), success (#7ED321), and warning (#F5A623) colors
- Typography using system fonts for optimal performance
- Spacing scale from 4px to 48px
- Border radius system (8px, 12px, 16px)
- Consistent shadow elevations
- Smooth animations (200ms, 300ms, 500ms)
