# Daily Flow

## The Complete Daily Rhythm

Engage structures the workday into four natural phases, each with its own purpose and experience.

---

## 🌅 Morning (7:00 AM - 9:00 AM)

### Purpose
**Set intention, establish focus, begin with awareness**

### The Sequence

#### 1. Wake-Up Screen
**First touch of the day**

```
Visual: Soft gradient (pale orange → mint → white)
Message: "Good morning, Sarah. Ready to make today count?"
Duration: 2 seconds or tap to continue
```

**Purpose:** Gentle entry into work mindset

#### 2. Mood Check-In
**"How are you feeling about work today?"**

```
5 Emotions:
😊 Ready
😌 Good
😐 Okay
😓 Tired
😰 Stressed

Optional: Text note (200 chars max)
```

**Purpose:** Establish emotional baseline for the day

#### 3. FlowBoard (Daily Command Center)
**"Here's what matters today"**

```
Priority #1: Largest card (40% of screen)
- AI-selected based on deadline, impact, energy, dependencies
- Clear next action
- Time estimate
- [Start This] button

Also On Your Plate: 3-5 smaller cards
- Quick-scan format
- Color-coded urgency
- Swipe to complete

Completed Today: Initially empty
- Fills as day progresses
```

**Purpose:** Clarity on what matters most

### User Feels
✅ Oriented ("I know what I'm doing today")
✅ Prepared ("I have a plan")
✅ In control ("This feels manageable")

---

## ☀️ Midday (10:00 AM - 2:00 PM)

### Purpose
**Make progress, maintain momentum, stay balanced**

### The Experience

#### Progress Mode
**Working on Priority #1**

```
Optional Focus Mode:
- Dims other tasks
- Shows timer (Pomodoro style)
- Mutes non-urgent notifications
- Exit anytime
```

**User Action:**
- Works on task
- Checks off sub-items
- Sees progress bar fill
- Gets small celebrations (sparkles) on completion

#### Coach Interventions
**AI suggests breaks when needed**

```
Example: "You've been focused for 90 minutes.
Your big presentation is later.
Time for a quick break?"

[Good idea] [Later]
```

**Trigger Logic:**
- 90+ minutes of continuous work
- Big event later in day
- Calendar shows break opportunity
- Historical pattern (user usually breaks at 10:30 AM)

#### Recognition Opportunities
**AI nudges appreciation**

```
Example: "Alex helped you yesterday.
Want to say thanks?"

[Give recognition] [Not now]
```

**Trigger Logic:**
- Recent collaboration detected
- User hasn't given recognition recently
- Alex's calendar shows they're available
- Good time (between meetings)

### User Feels
✅ Productive ("I'm getting things done")
✅ Supported ("The system helps me pace myself")
✅ Connected ("I'm reminded to appreciate others")

---

## 🌤️ Afternoon (2:00 PM - 5:00 PM)

### Purpose
**Collaborate, recognize, grow, prepare for closure**

### The Experience

#### Team Interactions
**KudosStream becomes active**

**User activities:**
- Receives recognition from others
- Gives recognition for morning collaboration
- Sees team wins in feed
- Reacts to others' recognition

#### Growth Activities
**GrowthHub engagement**

**User might:**
- Request feedback on presentation given today
- Complete 15-min learning module
- Review feedback themes
- Practice new skill

#### Preparation for Tomorrow
**AI pre-populates tomorrow's FlowBoard**

```
Based on:
- Incomplete tasks from today
- Calendar events for tomorrow
- Goal milestones coming up
- User's stated intentions
```

### User Feels
✅ Appreciated ("My work is seen")
✅ Developing ("I'm learning and growing")
✅ Prepared ("Tomorrow is already planned")

---

## 🌙 Evening (5:00 PM - 6:00 PM)

### Purpose
**Reflect, close loop, create psychological completion**

### The Sequence

#### 1. End-of-Day Prompt
**5:30 PM notification**

```
Coach: "Nice work today, Sarah.
Want to wrap up and reflect?"

[Yes, let's reflect] [Not today]
```

**Optional, never forced**

#### 2. Daily Reflection Screen
**"Today's Wrap-Up"**

```
Auto-Populated:
✅ What You Did
- Tasks completed
- Goals progressed
- Recognition given/received

Your Turn:
How did today feel? (5 emotions)
One win you're proud of (optional text)
One thing for tomorrow (optional text)
```

**Purpose:** Closure, gratitude, continuity

#### 3. Day Closed
**Completion ritual**

```
Visual: Gentle book-closing animation
Message: "Day closed. ✨ Rest well, Sarah."
Duration: 2 seconds
Result: Evening notifications muted (by default)
```

**Purpose:** Permission to disconnect

### User Feels
✅ Complete ("I finished the day properly")
✅ Accomplished ("I see what I did")
✅ Ready to rest ("Work is closed")

---

## 🌙 Evening (Optional: 8:00 PM)

### Optional Goodnight Message

```
Coach: "You wrapped up strong today.
Tomorrow's plan is set.
Rest well tonight."

[Preview tomorrow] [Good night]
```

**User Setting:**
- Default: OFF
- Opt-in only
- Purpose: Reduce evening anxiety about tomorrow

## The Daily Metrics

### What Engage Tracks

**Morning:**
- Check-in mood
- Time of first interaction
- Priority #1 selected by AI

**Midday:**
- Tasks completed
- Progress made on goals
- Focus time (if Focus Mode used)
- Breaks taken (if suggested and accepted)

**Afternoon:**
- Recognition given/received
- Team interactions
- Learning completed
- Feedback exchanged

**Evening:**
- Closing mood
- Reflection completed
- Tasks rolled to tomorrow

### What AI Learns

**Daily Patterns:**
- "Sarah is most productive 10 AM - 2 PM"
- "Energy dips on Mondays"
- "Works best with 2-hour focus blocks"
- "Prefers breaks around 10:30 AM and 3 PM"

**Weekly Patterns:**
- "Tuesday-Thursday are strongest days"
- "Fridays: lighter workload preferred"
- "Collaborates more early-week"

**Response to Interventions:**
- "Accepts break suggestions 80% of the time"
- "Engages with learning on Wednesday afternoons"
- "Gives recognition after receiving it"

## The Core Loop

```
MORNING             MIDDAY              AFTERNOON           EVENING
↓                   ↓                   ↓                   ↓
Set Intention   →   Make Progress   →   Connect & Grow  →   Reflect & Close
↓                   ↓                   ↓                   ↓
Wake-up            Work on Priority     Give Recognition    Daily Reflection
Mood Check         Complete Tasks       Learn & Develop     Close Day
See FlowBoard      Get Coach Nudges     Request Feedback    See Tomorrow
↓                   ↓                   ↓                   ↓
                                                            Rest
                                                            ↓
                                                        NEXT MORNING
                                                            ↓
                                                        (Loop Repeats)
```

## The Experience Philosophy

### What Makes This Work

**1. Predictable Structure**
- Same flow every day
- Familiarity builds habit
- Users know what to expect

**2. Optional Participation**
- Everything can be skipped
- No guilt for missing check-ins
- User controls pace

**3. Adaptive Intelligence**
- AI learns patterns
- Suggestions get better
- Experience personalizes

**4. Emotional Intelligence**
- Mood tracked, respected
- Celebrations built in
- Language is warm

**5. Closure-Oriented**
- Days have endings
- Weeks have boundaries
- Work doesn't bleed endlessly

## Success Indicators

### User is thriving when:
- ✅ Opens Engage voluntarily each morning
- ✅ Completes reflection most evenings
- ✅ Mood trends stable or improving
- ✅ Tasks completed consistently
- ✅ Recognition flowing regularly
- ✅ Growth activities engaged

### Warning signs:
- ⚠️ Skips check-ins for multiple days
- ⚠️ Mood declining over week
- ⚠️ No tasks completed for 2+ days
- ⚠️ No recognition given/received
- ⚠️ Login frequency drops

**When warnings appear:**
- AI alerts manager (aggregated, not specific)
- Coach increases supportive nudges
- Suggested "reset day" with lighter load
